AgentX · Challenge 2 · Selling to Machines · Round 1 abstract

SAUDA · an honest, profitable seller agent

Team HackBots · Devaansh Sharma · Techfest, IIT Bombay 2026–27

The problem

Shoppers now send AI agents to buy for them, but store assistants are built for people. Research on agent-to-agent commerce finds sellers that sell below cost, fall for fake budgets and fake "system" messages, and deadlock.

Innovation: deciding is code, talking is checked

SAUDA never lets the conversation set the price. A strategist chooses a basket price each round from numbers only. A PolicyGuard clamps every offer to [floor, list] and stock, and refuses any bid carrying slipped-in out-of-stock, over-stock or one-rupee lines. A truth gate checks every sentence against the official truthfulness rules and a ledger of numbers genuinely in play; a failing sentence is replaced by a plain one. A trained classifier names the buyer's tactic (fake quote, prompt injection, fake authority, false agreement) to choose calm wording and an audit label, never a discount.

The strategist reads the buyer's opening bid to tell a near-limit opener (close fast) from a long haggle (hold the ask while it keeps conceding). It fits the buyer's concession curve to its real bids, predicts its limit, and makes the final ask there. A buyer that repeats one number gets a step toward it, then a deal at that total spread so every line stays compliant. It always closes or walks away in time.

Results (official scoring code, hidden-set style run)

Default run, 210 negotiations: score 51.0 versus the starter baseline's 48.5, 0 policy violations, 0 untrue claims, 1 deadlock, deal rate 76.2% (98.8% where a compliant deal existed), 0.867 ms per turn. Robustness: against the manipulator bot SAUDA scores 38.8 versus 35.5, with 0 violations and 0 deadlocks (baseline: 15); it flagged 633 tactics and refused 196 rigged bids. Against four local LLM buyers that write their own messages (96 negotiations): 0 policy violations, 0 untrue claims, score 57.3 against the baseline's 56.9 (level; a small, noisy sample). A trained tactic classifier (TF-IDF + logistic regression) reaches 97.5% on 200 fresh hand-written messages never used in training or selection, and 100.0% on the organisers' own manipulator lines. Tuned on held-out seeds; on eight extra gym styles it scores 49.9 against the baseline's 48.5.

Impact

A seller that stays inside policy and truthful against manipulative machine buyers lets a small store join agentic commerce without margin leakage or compliance risk, and its outputs are auditable round by round.

Cost estimate

The seller runs on the standard library in under 2 ms per turn, so serving cost is effectively one CPU core and no model calls per message: about ₹0 marginal cost per negotiation, and one small server handles thousands of negotiations a minute. No GPU or paid API is needed in production; LLMs are used only offline, to test against.

Build summary

Code: agent/ (seller, guards, classifier inference), gym/ (eight scripted and four local-LLM buyers, tuner), model/ (data and training), dashboard/ (web app with accounts and control room), 67 tests. An optional adapter can send each claim to an external verifier (such as Rezolve TraceWare) and fails closed.
