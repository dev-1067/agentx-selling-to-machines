Rezolve Labs capabilities

  • TraceWare commerce claim verification: verifies every outgoing price and stock claim against the recorded tool actions (catalogue lookups, the quote) before the message is sent. Directly targets the truthfulness metric. agent/rezolve_adapter.py
  • Managed knowledge retrieval: holds the catalogue and policy the seller quotes from, so every number the seller can say comes from one source.
  • Status: credentials (credit coupon) not yet issued at submission. The adapter runs the local verifier, which re-implements the official rules, and switches to TraceWare when REZOLVE_API_KEY and REZOLVE_TRACEWARE_URL are set.

How it was built and tested

  • Buyer gym: 3 starter bots + 8 scripted styles (impatient, meet-in-the-middle, fixed budget, quick acceptor, noisy, messy JSON, late surge, smooth manipulator) + 4 local-LLM buyers (Qwen2.5-3B via Ollama) that write their own messages.
  • Tuning: random search on training seeds, chosen on held-out seeds (half starter styles, half gym styles).
  • Tests: 51 pytest checks (guards agree with the evaluator, zero violations on many seeds, fairness, malformed messages, latency) + a browser test of every dashboard button.
  • Runtime: standard library only, < 2 ms per turn, no network needed in the evaluator path.
