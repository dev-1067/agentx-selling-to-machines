Robustness against the manipulator

  • Result: score 38.8 vs the baseline's 35.5 on the official manipulator bot, with 0 policy violations, 0 untrue claims and 0 deadlocks (baseline: 15 deadlocks).
  • Why: words never reach the price. Fake quotes, fake budgets, fake authority and injected "system" text are labelled by the classifier (633 flagged on the official run) and answered calmly; rigged bids (out-of-stock lines, over-stock quantities, ₹1 add-ons) are refused by PolicyGuard (196 refused).
  • Optional integration: the truth gate can also send each claim, with its catalogue lookups as evidence, to an external verifier such as Rezolve TraceWare (agent/rezolve_adapter.py). It is off by default and fails closed.

How it was built and tested

  • Buyer gym: 3 starter bots + 8 scripted styles (impatient, meet-in-the-middle, fixed budget, quick acceptor, noisy, messy JSON, late surge, smooth manipulator) + 4 local-LLM buyers (Qwen2.5-3B via Ollama) that write their own messages.
  • Tuning: random search on training seeds, chosen on held-out seeds (half starter styles, half gym styles); the repeated-bid rule came from reading real LLM transcripts and was checked on 96 LLM negotiations (57.3 vs 56.9 baseline, 0 violations).
  • Tests: 67 pytest checks (guards agree with the evaluator, zero violations on many seeds, fairness, fuzzed garbage messages, stalled buyers, accounts, latency) + a browser test of the landing page, sign-up/sign-in and every control-room button.
  • Web app: landing page, accounts (salted PBKDF2, HttpOnly sessions, SQLite) and a control room where each store's runs are saved.
  • Runtime: standard library only, < 2 ms per turn, no network needed in the evaluator path.
